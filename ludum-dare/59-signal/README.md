## About

Ludum Dare is a 72-hour game jam. This repo holds the full development trail —
brainstorm, specs, devlog posts, screenshots, source — captured live over the
weekend.

See `devlog/` for micro-blog updates as the jam unfolds, and `specs/` for the
locked-down design of whatever we end up building.

## Repo layout

See [`CLAUDE.md`](CLAUDE.md) for the full map. Short version:

- `specs/` — game design, one doc per subsystem
- `devlog/` — timestamped update posts (mirrored to the jam site)
- `screenshots/` — devlog + submission assets
- `.claude/` — Claude Code harness (skills, hooks, plans)
- `.beads/` — bead task tracking
