Made a phone puzzle over the weekend. Rewrote it four times first.

**What it is:** you're a 1940s switchboard operator handling some very zany, zany calls. (🐐) Two unrelated callers ended up tangled on the same wire. Sort each line back to where it belongs.

This one continues something I've been running in the [same repo](https://github.com/azigler/coding-jams). For [Genuary 2026](https://github.com/azigler/coding-jams/tree/main/genuary/2026) I ran a daily creative-coding agent for 31 days — each piece shipped with its own [manifesto](https://github.com/azigler/coding-jams/tree/main/genuary/2026/.claude/manifesto) logging what I refused, what I chose, and why, plus a daily prompt and constraint set. For LD59 I pointed the same habits at the "Signal" theme: the agent bootstrapped this weekend's [Claude Code](https://claude.com/claude-code) harness, looped on ideation, and prototyped several directions I threw out along the way.

The pixel art came out of a pipeline I tuned during Genuary — the agent drafts image prompts, Nanobanana on Gemini renders them, I clean up transparency in Figma and scale 2–3× down for crisp pixels. Jam culture is rightly wary of AI code and AI art. To be straight about it: the design calls, the dialogue voices, and the *what I refused and why* lists are mine; the agent handled code drafts against my specs and the image-prompt pipeline described above. The agent accelerates the making. It doesn't make the taste.
