# LinkedIn draft

Following up on [Genuary 2026](https://azigler.github.io/coding-jams/genuary-2026/) — the daily creative-coding project I posted through here all January. The same harness I used for those 31 pieces built a 72-hour Ludum Dare game this weekend.

The harness is a growing set of [Claude Code](https://claude.com/claude-code) skills I keep extending — spec, impl, review, manifesto, taste, commit discipline — that codify the habit of making something every day. Each Genuary piece shipped with its own [manifesto](https://github.com/azigler/coding-jams/tree/main/genuary/2026/.claude/manifesto) tracing what I refused and what I chose. For Ludum Dare 59 I pointed the same habits at the jam theme: **Signal**.

**→ Play CROSSED WIRES:** https://ldjam.com/events/ludum-dare/59/crossed-wires

A 1940s switchboard operator. Two unrelated callers end up tangled on the same wire. You sort each utterance back to where it belongs. By the final level, static eats the topic words and you sort by *how* each caller talks — voice as the only signal.

And one prototype I killed along the way — kept playable as evidence of what the harness refused:

**→ Play Phase Chorus:** https://azigler.github.io/coding-jams/ld59/prototypes/phase-chorus/

Kuramoto-coupled fireflies synchronizing their pulses. Beautiful physics, almost no agency. A reference for what got rejected and why.

**On AI.** Jam culture is rightly wary of AI code and AI art, and I want to be specific. The agent drafts image prompts that I then run through Nanobanana (Gemini), clean up transparency in Figma, and downsample 2–3× for pixel crispness. It writes code against specs I author. The design decisions, dialogue voices, and every *what I refused* list are mine. The agent accelerates the making. It doesn't make the taste.
