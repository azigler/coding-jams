# UI/UX Specification

## Desktop Interface

1. **Layout**
   - Full screen desktop environment
   - Two draggable windows
   - Clock in top-right corner
   - Simple desktop background

2. **Window System**
   - Basic window dragging
   - Minimize/maximize buttons
   - Window focus management
   - Fixed window size

## Mail Application

1. **Interface Elements**
   - Simple inbox list
   - Email reading pane
   - Basic email formatting
   - No compose functionality

2. **Visual Style**
   - Clean email layout
   - Basic formatting (bold, paragraphs)
   - Highlighted important text
   - System-style interface

## Server Application

1. **Navigation**
   - Folder list view
   - Double-click to open
   - Back button
   - Current path display

2. **Visual Elements**
   - Folder icons
   - File icons
   - Simple hover effects
   - Basic selection highlight

## Feedback Elements

1. **Timer Display**
   - Large, visible clock
   - Color changes when time low
   - Simple countdown animation

2. **State Feedback**
   - Click animations
   - Hover highlights
   - Window focus effects
   - Success/failure overlays

## Accessibility

- High contrast colors
- Clear text hierarchy
- Large clickable areas
- Distinct visual feedback
