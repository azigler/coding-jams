# Content Specification

## Email Content

1. **Boss Email**

   ```
   Subject: URGENT!!! Need file ASAP!!!
   From: Boss McBossface
   To: You
   
   Hey there superstar!
   
   Big emergency! VIP client needs the [TARGET_FILE] right now!
   They're literally in my office breathing down my neck!
   
   You have ONE MINUTE to find it in the server or we're all DOOMED!
   
   No pressure! 😅
   
   - Boss
   P.S. Don't ask why it's buried in random folders. IT said something about "security through obscurity"...
   ```

## Folder Structure

1. **Depth Rules**
   - Minimum 5 folders deep
   - Maximum 8 folders deep
   - 3-10 items per folder
   - Mix of files and folders

2. **Naming Themes**
   - Corporate buzzwords
   - Meme references
   - Food items
   - Random emoji
   - Deliberately confusing names

3. **Example Folders**
   - "Very Important Stuff"
   - "Definitely Not Memes"
   - "Meeting Notes (REAL)"
   - "🍕_Friday_Orders"
   - "System32 (Not Really)"

4. **Example Files**
   - "final_final_v2_REAL.doc"
   - "dont_open_this.exe"
   - "cat_pictures_2023.zip"
   - "homework_folder_nothing_sus.txt"
   - "[TARGET_FILE]"

## Success/Failure Messages

1. **Success**

   ```
   YOU DID IT!
   Crisis averted! Boss is happy!
   The client probably won't fire us now!

2. **Failure**

   ```
   TIME'S UP!
